## Намасте 🙏
Я — Windows-энтузиаст. Занимаюсь кибербезопасностью, системным администрированием и автоматизацией. Здесь Вы найдете различные скрипты моего авторства, cборку Total Commander, а также вики-блог в виде заметок.

### 📜 scripts
Несколько десятков скриптов, решающие различные задачи по автоматизации Windows.  
В основном это `bat`, а также `ps1` и `ahk`.  
**[Смотреть все...](https://github.com/wincmd64/scripts)**

### 💾 totalcmd
Компактная сборка с минимальным количеством стороннего ПО.  
Всегда актуальная версия: обновления каждый месяц.  
**[Подробнее...](https://github.com/wincmd64/blog/wiki/TotalCmd)**
